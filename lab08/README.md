# Крестики-нолики (Tic-Tac-Toe)

## Описание

**Крестики-нолики** — классическая логическая игра для двух игроков на доске 3×3. Целью каждого игрока является составить линию из трёх своих символов (горизонтально, вертикально или диагонально).

Приложение реализовано с использованием:
- **Фреймворк GUI**: Tkinter
- **Парадигма**: Объектно-ориентированное программирование (ООП)
- **Обработка ошибок**: Собственные исключения

## Требования

- Python 3.7 или выше
- Tkinter (поставляется с Python)

## Краткая справка

### Правила игры

1. **Игроки**: X и O
2. **Доска**: сетка 3×3 (9 клеток)
3. **Ход**: игроки ходят по очереди, начиная с X
4. **Победа**: первый, кто составит 3 своих символа в ряд (горизонталь, вертикаль или диагональ)
5. **Ничья**: если все клетки заполнены, но никто не выиграл

### Управление

- **Клик на клетку**: сделать ход в выбранную позицию
- **Кнопка "Новая игра"**: начать новую игру (сбросить доску)
- **Кнопка "Выход"**: закрыть приложение

### Обозначения

- **X** — крестик (первый игрок, синий цвет)
- **O** — нолик (второй игрок, оранжевый цвет)
- **Пустая клетка** — доступно для хода

## Архитектура

### Структура классов

#### `Player` (Enum)
Перечисление для представления игроков и пустых клеток.

#### `TicTacToe`
Основной класс игровой логики, содержит:
- `__init__()`: инициализация доски и игрового состояния
- `make_move(row, col)`: выполнение хода
- `_check_winner(player)`: проверка победы
- `_is_board_full()`: проверка полноты доски
- `reset()`: сброс игры
- `get_board_state()`: получение состояния доски

#### `TicTacToeApp`
Класс для GUI приложения, содержит:
- `__init__(root)`: инициализация интерфейса
- `_create_widgets()`: создание элементов интерфейса
- `_on_button_click(row, col)`: обработчик клика
- `_update_display()`: обновление отображения
- `_reset_game()`: сброс игры

### Исключения

1. **GameException**: базовое исключение для всех ошибок игры
2. **InvalidMoveException**: выбрасывается при невалидном ходе
3. **GameOverException**: выбрасывается при попытке хода в закончившейся игре

## Примеры использования

### Как использовать класс `TicTacToe` программно:

```python
from lab08 import TicTacToe, InvalidMoveException

# Создание новой игры
game = TicTacToe()

# Выполнение ходов
try:
    game.make_move(0, 0)  # X ходит в верхний левый угол
    game.make_move(1, 1)  # O ходит в центр
    game.make_move(0, 1)  # X ходит
    game.make_move(2, 2)  # O ходит
    game.make_move(0, 2)  # X выигрывает (верхняя строка)
except InvalidMoveException as e:
    print(f"Ошибка: {e}")

# Проверка результата
if game.winner:
    print(f"Победитель: {game.winner.value}")

# Сброс для новой игры
game.reset()
```
